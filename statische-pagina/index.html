Self-hosted setup

OThe goal is to build an infrastructure that is secure, useful, and explainable, not merely accumulating services, but selecting tools that address real needs.

Central issue
How can multiple services be kept accessible on the internet without losing control over security, data, and maintenance?

The solution is treated as a living system: each container has a specific function, well-defined relationships, and only the necessary access. A reverse proxy organizes incoming traffic, authentication provides protection, backups ensure preservation and versioning tracks evolution.

03 / in-house application

Poll Manager

A voting system as an object of study.

A full-stack application for creating polls, making them available for a set period, and tracking votes. The project separates the client from the server and keeps the database isolated from the public internet.
